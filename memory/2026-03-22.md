## taskbus 定时任务系统

完成了 Daniel agent 的任务领取→下载→读取流程：

### 脚本结构
```
scripts/
├── taskbus_claim.sh      # 主脚本：检查并领取任务，调用下载
├── taskbus_download.sh    # 下载任务文件（解析 fileUrl）
└── daniel_read_task.sh    # Daniel 读取当前任务书

tasks/                     # 任务文件存放目录
├── current_task.txt       # 当前任务路径（标记文件）
└── <任务名>_<时间戳>.md   # 具体任务书
```

### 流程
1. `taskbus_claim.sh` 每分钟运行（crontab），检查 pending 任务
2. 有任务时调用 `taskbus claim -e daniel` 领取
3. 提取任务 ID，调用 `taskbus_download.sh <id>` 下载
4. 下载脚本调用 `taskbus get <id>` 获取 fileUrl
5. curl 下载文件到 `tasks/` 目录
6. 写 `current_task.txt` 标记当前任务路径
7. Daniel 运行 `daniel_read_task.sh` 读取任务书
